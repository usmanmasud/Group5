Objective

This repository is for our group to practice basic collaboration using GitHub. The focus is on learning how to work together by sharing code, making updates, and managing contributions from all members.

---

Tasks

1. Add All Members as Collaborators

- Ensure every group member has been added to this repository.

2. Each Member Should:

- Clone the repository to their system
- Create or edit a file
- Commit their changes
- Push updates back to GitHub

---

Steps to Follow

Clone the Repository

git clone <repository-link>

Make Your Contribution

- Create a file or edit an existing one
- Example: Add your name to "contributors.txt"

Commit Your Work

git add .
git commit -m "Added my contribution - <your name>"

Push to GitHub

git push origin main

Stay Updated

Before starting new work:

git pull origin main
